# NeutralMean7外部使用说明

本交付适用于Freqtrade 2026.9。`.qstrat`是本项目定义的ZIP策略包，需要通过安装器安装，不能直接在Freqtrade中选择文件后原生导入。

1. 在项目的Python环境运行：

   `python install_qstrat.py NeutralMean7.qstrat --userdir "你的Freqtrade用户目录"`

   安装器先核对全部路径、SHA256和文件冲突，再写入策略目录。已有相同文件可重复安装；已有不同版本会拒绝覆盖，请使用新的用户目录或自行备份后管理版本。

2. 策略名称为`NeutralMean7Portable`。使用自己的配置文件，设置`trading_mode=spot`、`BTC/USDT`、单仓；用`--userdir`明确指定刚安装的用户目录。先使用dry_run。安装包不含账户或交易所密钥，也不会自动启动服务。

3. 回测时仍需要Freqtrade标准数据目录中的BTC/USDT小时行情。包内历史是指标状态种子，不替代Freqtrade行情目录。复现基础场景采用单边fee=0.0015、10000 USDT，1h主框架，UTC01:00。压力别名为`NeutralMean7PortableLag2`，fee=0.003、UTC02:00。

4. 长期运行会更新`user_data/neutralmean7_state/history_1h.feather`。保留该目录跨重启。如果离线时间过长而小时历史不连续，先补齐历史或恢复状态；策略会拒绝无法桥接的种子/输入缺口。不要把未结束日线作为完成信号输入。

5. 包将原模型转换为JSON数值推断，运行时无需sklearn或joblib；原始模型对照测试误差为零。优先使用包内requirements-tested.txt所列版本；其他操作系统或版本未在本交付验证。

完整回测与验证见《验证与回测报告.md》和PPT。模型、日目标及订单一致性已验证，但历史收益不构成未来收益保证；多起点窗口属于开发期敏感性检查，不是独立盲测。
